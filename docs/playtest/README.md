# Playtest — alpha с друзьями (5-10 человек)

Чтобы перевести игру из «откалибровано симуляциями» в «откалибровано живыми руками», нужны три источника данных:

| Источник | Что даёт | Файл |
|---|---|---|
| **A. .json-отчёт из игры** | Цифры: куда дошёл, какие решения, ачивки, сервисы | сэйв-экспорт в UI + `replay.mjs` |
| **B. Google Form** | Ощущения структурно: понятно ли, бесило ли, дошёл/сдался | `google-form-questions.md` |
| **C. 30-мин звонок** | Поведение live: где залипает, что не понимает | `playtest-call-script.md` |

## Workflow

### Перед запуском плейтеста

1. Развернуть текущую ветку на доступной ссылке (Vercel/Netlify/GH Pages) — `npm run build` + `dist/` куда-то закинуть
2. Создать Google Form по шаблону из `google-form-questions.md`
3. Подготовить чат / личные сообщения с приглашением:

```
Привет! Делаю экономический симулятор «Бизнес с Контуром» — управление
малым бизнесом 52 недели, выбор тактик, события, сервисы. Хочу попросить
тебя его попробовать (30-60 минут) и прислать фидбек. Игра по ссылке: <URL>
После — заполни короткую форму: <URL>. Спасибо!
```

### Во время плейтеста

Тестер:
1. Заходит по ссылке, играет
2. В конце (или когда сдался / прошёл) — открывает Настройки → «📥 Скачать отчёт для плейтеста» → получает .json
3. Заполняет Google Form, прикрепляет .json

### После сбора

```bash
# Прогнать batch отчётов
node docs/playtest/replay.mjs reports/*.json

# Получится: краткие postmortem'ы + сводка «5 тестеров: 2 победы, 3 game-over (2 burnout, 1 bankrupt)»
```

Google Forms ответы экспортнуть в Sheets, посмотреть:
- Распределение оценок 1-10
- Wordcloud «3 вещи которые бесили»
- Корреляция «дошёл-не дошёл» с типом бизнеса

С теми кто отметил «готов созвониться» — назначить 30-минутный звонок (см. `playtest-call-script.md`).

### Сведение в action-list

После 5-10 тестеров + 3-5 звонков должны проявиться **повторяющиеся** жалобы. Если 3+ человека жалуются на одно — это HIGH priority фикс.

Один человек жалуется на что-то — не делать вывод сразу, дождаться второго сигнала.

## Что НЕ делать

- ❌ Тестировать только на коллегах-геймдевелоперах. Их фидбек смещён в сторону анализа, не эмоций.
- ❌ Спрашивать «понравилось?» — все ответят «да, классно». Спрашивать конкретно: «где залипал?», «что было непонятно?».
- ❌ Защищать дизайн в комментариях формы или звонка. Только слушать.
- ❌ Решать «надо переделать всё» после одного жалующегося. Дождаться паттерна.
