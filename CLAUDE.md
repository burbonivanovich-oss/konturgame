# Бизнес с Контуром — CLAUDE.md

Экономический симулятор управления малым бизнесом. Игрок выбирает тип бизнеса (магазин, кафе, салон красоты) и ведёт его 52 недели. Ключевая механика: 6 сервисов Контура решают реальные игровые проблемы и демонстрируют их ценность игроку. У игрока есть личная цель (1.0-1.2М ₽) с дедлайном — основная мотивация наряду с «не обанкротиться».

**Стек:** React 18 + TypeScript + Vite + Zustand + Tailwind CSS

## Команды

```bash
npm run dev          # локальный сервер http://localhost:5173

```

### Касса по 54-ФЗ (compliance, не апгрейд)

Раньше было 3 типа касс с throughput-механикой (mobile/reliable/fast, 25/50/80 чел/день), comboскидками и поломками. Удалено: касса перестала быть механикой развития, стала одноразовой compliance-покупкой. Реальная мех. throughput почти не кусала (только в узком mid-game window) и мешала пониманию: дневная плитка «98/98» в недельной игре сбивала с толку.

Текущая модель: один action `purchaseFiscalCompliance()` — списывает 24 000 ₽ (ККТ + ФН), ставит `fiscalDriveOwned: true`. Поле `cashRegisters: CashRegister[]` оставлено в state для совместимости со старыми сэйвами, всегда `[]`. Achievement `first_register` теперь проверяет `fiscalDriveOwned`. Онбординг шаг `buy_register` тоже.

## Что реализовано

- **Игровой цикл:** `processWeek()` — 7 дневных итераций, 4-фазный недельный цикл (Сводка → Действия → События → Результаты) реализованы как полноэкранные overlay'и
- **Сервисы:** 6 сервисов Контура (Маркет, Банк, ОФД, Диадок, Фокус, Эльба) + синергии. Экстерн скрыт из UI
- **Личные цели:** 3 backstory-варианта (close_debt 1.0М к W46, brother_tuition 1.1М к W48, own_apartment 1.2М к W50)
- **Тактики недели:** aggressive (+18% выручки, -9 энергии и -1.4 реп/нед), calm (+17 энергии/нед), service (+5.6 реп +3.5 лояльности/нед)
- **Найм через события:** solo_overload (W5-6) → first_hire chain (W7-8). Светлана отдельным сюжетом на W20+ с мостами от Михаила и дневника
- **Сотрудники:** реальная система Employee + чейн «увольнение Олега» (oleg_trouble_1/2). Найма через апгрейды больше НЕТ
- **Достижения:** 20 достижений в 4 категориях
- **События:** 19+ событий с Контур-альтернативами + микрособытия
- **Реклама:** 10 кампаний, Campaign ROI аналитика
- **Улучшения:** 24 апгрейда (8 на каждый тип бизнеса) с requirements/depths, monthly cost warnings в UI
- **Поставщики:** 6 штук (economy×2, standard×2, premium×2)
- **Качество:** `qualityLevel` 0-100, влияет на репутацию, лояльность, средний чек
- **Pain Engine:** показывает потери от отсутствия каждого сервиса
- **Онбординг:** 15 шагов, 4 стадии. Skip-логика исправлена
- **Defer events:** «Подумаю позже» — одна отсрочка на событие
- **Burnout warning:** при первом обнулении энергии показывается красный warning, второе обнуление = game over
- **Personal goal:** сохраняется в localStorage, диалоговые dilemma с дедлайнами
- **NPC система:** 6 NPC с relationship, memory, arcs. Гейтинг чейнов по revealed-статусу
- **Owner investments:** Quality of life (кресло, ноутбук, абонемент) ✅ работает
- **Промо-коды:** `PromoCodeModal`, `PromoWalletModal`, `BundleModal`
- **Микрособытия:** отдельный слой мелких событий
- **Займы, вехи, ассортимент, мобильный layout** — всё работает
- **Касса по 54-ФЗ:** одноразовая compliance-покупка (ККТ + ФН за 24 000₽). Никаких типов/throughput/поломок — выпилено в этом коммите
- **Manager bonus:** Светлана-управленец усиливает команду +25% (assistants) / +40% (specialists)
- **Employee growth/decay:** Никита растёт 0.85→1.05, Олег падает 1.0→0.9, под Светланой Олег скисает до 0.75
